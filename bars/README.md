# Frozen bars

Use the newest directory. `national-v7` is current: the version-three set, frozen on
nine qualification worlds under the hidden source regime, with all eight controls
failing a named gate on every one of them and the sealed world index 4 confirmed
against it. See `national-v7/PROVENANCE.md`. Earlier versions are kept as the record of
the freezes they superseded. `national-v7/achieved_v2.json` records what the
version-two trajectory achieved against `national-v6`, and `national-v7/PROVENANCE.md`
lists that achieved value beside every version-three bar.
