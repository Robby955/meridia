# Frozen bars

Each directory is one freeze. `national-v14-standard` is the newest and the only
version-four set that records `"frozen": true`, so it is the only one that can decide a
version-four verdict. It was frozen under the `standard` gate profile on six qualification
worlds, and it carries its own blockers and caveats in `bars.json`.

`national-v14-full` and `national-v14-lite` read the same evidence under the other two
registered profiles. Both record `"frozen": false`, as do every version-four set from
`national-v8` through `national-v13`. Read those as the record of an open calibration, not
as thresholds a submission must clear.

`national-v7` is the version-three set and the last one before version four to gate a
submission. It was frozen on nine qualification worlds under the hidden source regime,
with every registered control failing a named gate on all of them and the sealed world
index 4 confirmed against it. See `national-v7/PROVENANCE.md`, which lists what the
version-two trajectory achieved against `national-v6` beside every version-three bar.

Earlier versions are kept as the record of the freezes they superseded.
