# Frozen bars

Each directory is one freeze, and the newest is `national-v10`.

`national-v7` is the version-three set and the last one that gated a submission. It was
frozen on nine qualification worlds under the hidden source regime, with all eight
controls failing a named gate on every one of them and the sealed world index 4 confirmed
against it. See `national-v7/PROVENANCE.md`. `national-v7/achieved_v2.json` records what
the version-two trajectory achieved against `national-v6`, and `national-v7/PROVENANCE.md`
lists that achieved value beside every version-three bar.

`national-v8`, `national-v9`, and `national-v10` are the version-four sets. All three
record `"frozen": false` in `bars.json`, so none of them can decide a version-four
verdict. `national-v10` names its one remaining blocker and its caveats in `bars.json`.

Earlier versions are kept as the record of the freezes they superseded.
